Aggiungi provider LLM

La chiave è cifrata a riposo e usata solo per costruire il client LLM. Non viene mai inviata al modello né condivisa con altri utenti.

Connetti AWS (SSO)

Inserisci l'URL del portale SSO della tua organizzazione (es. https://azienda.awsapps.com/start). Richiede che la tua organizzazione abbia AWS IAM Identity Center attivo. Se non ce l'hai, usa le chiavi statiche come fallback.

Connetti AWS (chiavi statiche)

Fallback per chi non ha AWS IAM Identity Center (SSO). Le credenziali sono cifrate a riposo e usate solo per costruire il client AWS. Consiglio: crea un IAM user dedicato con permessi minimi.

Configura Azure DevOps

Azure DevOps riusa la sessione Azure: connetti prima Azure (stesso account Microsoft), poi indica qui il nome della tua organization (es. mycompany — senza dev.azure.com).

Configura GitHub OAuth (BYOK)

GitHub non permette connessioni anonime: serve una OAuth App creata sul tuo account. Il Client ID non è un segreto e resta salvato solo sul tuo profilo Hemmy.

1. Vai su GitHub → Developer settings → OAuth Apps.
2. Crea una nuova OAuth App (nome a piacere, homepage qualsiasi).
3. Apri l'app e abilita Device Flow.
4. Copia il Client ID e incollalo qui sotto.

Connetti Airflow

Supporta Basic Auth (Airflow 2.x self-hosted) e Bearer Token (Airflow 3.x, Astronomer, MWAA con token). La connessione viene testata al salvataggio chiamando /api/v1/health: se fallisce, non salviamo nulla.
